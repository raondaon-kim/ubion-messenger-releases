
# UBION Messenger 다운로드

UBION 사내 메신저(DaouOffice) 데스크톱 앱의 **설치 파일 배포 전용** 저장소입니다. 소스 코드는 포함되어 있지 않습니다.

👉 **[최신 버전 다운로드](../../releases/latest)**

| OS | 파일 |
|---|---|
| Windows | `UBION-Messenger-x.y.z-Setup.exe` |
| macOS (Apple Silicon) | `UBION-Messenger-x.y.z-arm64.dmg` (릴리스에 있을 때) |
| macOS (Intel) | `UBION-Messenger-x.y.z-x64.dmg` (릴리스에 있을 때) |
| Android | `UBION-Messenger-x.y.z-android.apk` (릴리스에 있을 때, 시험용) |

- Windows: 이 저장소의 설치 파일로 설치한 앱은 새 버전을 자동으로 받아, 앱을 종료하거나 '재시작하여 설치'를 누르면 설치합니다.
- 1.0.29 이하(이전 배포처에서 받은 설치본)는 이 저장소를 보지 않습니다. 한 번만 여기서 받아 설치하면 이후부터 자동 업데이트됩니다.
- 현재 설치 파일은 코드 서명이 없습니다. Windows SmartScreen이 경고하면 '추가 정보' → '실행'을 누르세요.
- Android: 시험용 빌드입니다. 폰에서 apk를 받아 '출처를 알 수 없는 앱 설치'를 허용하고 설치합니다. 자동 업데이트는 없으니 새 버전이 나오면 다시 받아 덮어 설치하세요.
