# UBION Messenger 다운로드

UBION 사내 메신저(DaouOffice) 데스크톱 앱의 **설치 파일 배포 전용** 저장소입니다. 소스 코드는 포함되어 있지 않습니다.

👉 **[최신 버전 다운로드](../../releases/latest)**

| OS | 파일 |
|---|---|
| Windows | `UBION-Messenger-x.y.z-Setup.exe` |
| macOS (Apple Silicon: M1·M2·M3·M4 …) | `UBION-Messenger-x.y.z-arm64.dmg` |
| macOS (Intel) | `UBION-Messenger-x.y.z-x64.dmg` |
| Android | `UBION-Messenger-x.y.z-android.apk` (시험용) |

`-mac.zip`, `.blockmap`, `latest*.yml` 파일은 앱의 업데이트 확인용입니다. 받지 않아도 됩니다.

## Windows

- 이 저장소의 설치 파일로 설치한 앱은 새 버전을 자동으로 받습니다. 앱을 종료하거나 '재시작하여 설치'를 누르면 설치됩니다.
- 1.0.29 이하(이전 배포처에서 받은 설치본)는 이 저장소를 보지 않습니다. 한 번만 여기서 받아 설치하면 이후부터 자동 업데이트됩니다.
- 설치 파일에 코드 서명이 없습니다. Windows SmartScreen이 경고하면 '추가 정보' → '실행'을 누르세요.

## macOS

**1. 내 Mac에 맞는 파일 고르기**

화면 왼쪽 위  메뉴 → '이 Mac에 관하여'에서 '칩'을 확인합니다.

- Apple M1·M2·M3·M4 … → `arm64.dmg`
- Intel → `x64.dmg`

**2. 설치**

1. 받은 DMG를 엽니다.
2. UBION Messenger 아이콘을 '응용 프로그램(Applications)' 폴더로 끌어 넣습니다. 이미 설치돼 있으면 '대치'를 누릅니다. 로그인 정보는 그대로 남습니다.

**3. 처음 열기 (한 번만)**

아직 Apple 서명이 없는 앱이라 처음 열 때 macOS가 막습니다.

1. 앱을 열면 "Apple은 … 악성 코드가 없음을 확인할 수 없습니다" 창이 뜹니다. '완료'를 누릅니다.
2. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래쪽 보안 항목의 **'그래도 열기'**를 누른 뒤 암호를 입력합니다.
3. 다시 뜨는 확인 창에서 '열기'를 누릅니다.

그래도 열리지 않으면 터미널에서 아래 명령을 실행한 뒤 다시 엽니다.

```
xattr -cr "/Applications/UBION Messenger.app"
```

**4. 업데이트**

- 1.0.37 이상: 새 버전이 나오면 앱이 알려 주고 DMG를 받아 열어 줍니다. 앱을 '응용 프로그램' 폴더에 다시 끌어 넣어(대치) 설치합니다. Windows처럼 자동 설치되지는 않습니다.
- 1.0.29 이하: 새 버전을 찾지 못합니다. 이번 한 번은 직접 받아 위 방법으로 설치해 주세요.

**알아 둘 점**

- 서명이 없어 macOS에서는 메신저 알림이 뜨지 않습니다. Apple 서명을 적용하면 알림이 켜지고 '그래도 열기'도 필요 없어집니다(예정).
- 지원 버전: macOS 13(Ventura) 이상.

## Android

- 시험용 빌드입니다. 폰에서 apk를 받아 '출처를 알 수 없는 앱 설치'를 허용하고 설치합니다.
- 자동 업데이트가 없습니다. 새 버전이 나오면 다시 받아 덮어 설치하세요. 덮어 설치하면 로그인이 유지됩니다.
